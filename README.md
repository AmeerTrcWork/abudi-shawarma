# Aboud Siria Demo Website

Independent demonstrative project for a Syrian restaurant concept in São Paulo.

## Scope

This project is a design and conversion-oriented landing page demo built for presentation to the restaurant owner as a sales proposal concept. It is not presented as the official website of the business, and no unverified facts were added as if they were confirmed.

- React Icons
